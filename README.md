# That's Me!

A spelling game that helps young children learn to spell and say their own name.
A grown-up types the name once in Settings; the child plays three levels:

1. **Build** – drag the scrambled letters into place.
2. **Dino dig** – dig the buried name out of the dirt with a shovel.
3. **Sand trace** – trace the name in handwriting letters at the beach.

Every letter is spoken when touched, and the whole name is spoken when it's finished.
Built with Expo (SDK 54). Plays in landscape on iPhone and iPad.

## Run it
- Snack: paste `App.js` into a Snack and add the packages it asks for.
- Locally: `npm install`, then `npx expo start`.

## Build for TestFlight

See `eas.json` for build profiles; `production` builds auto-increment the build number.
